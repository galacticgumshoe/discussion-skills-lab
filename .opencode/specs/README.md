# Task specifications

Put a multi-session task or milestone specification here when the work is large
enough to plan before implementation: scope, prerequisites, approved decisions,
required checks and stop conditions.

- One file per task or milestone, named for the work (for example `feature-x.md`).
- Write it before editing and keep it accurate if the approved scope changes.
- Do not store execution evidence, screenshots, test reports or session handoffs
  here. Those belong with the work itself — the session record, issue or pull
  request — using the format in
  [`.opencode/docs/handoff-template.md`](../docs/handoff-template.md).
- Current architecture and open issues are in
  [`.opencode/docs/`](../docs/).
